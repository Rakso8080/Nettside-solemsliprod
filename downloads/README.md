# Downloads

Place your digital product files here:

- `cinematic-powergrade-pack.zip` — Cinematic Powergrade Pack
- `cinematic-blue.zip` — Cinematic Blue LUT
- `warm-sunset.zip` — Warm Sunset LUT
- `moody-dark.zip` — Moody Dark LUT
- `lut-pack.zip` — LUT Pack (all LUTs)
- `nordic-tone.zip` — Nordic Tone LUT
- `portrait-pro.zip` — Portrait Pro LUT

## How to add files
1. Export your LUTs/powergrades from DaVinci Resolve
2. Zip each file
3. Place in this folder with the exact filename above
4. Commit and push
